## 🕹️ 二、全要素民俗互动与全域节庆热度系统

画面底部常驻**核心交互提示**与**全域节庆热度**：
```text
🏮 热度: 666  [ENTER]华彩盛典  [SPACE]绚烂烟花  [TAB]切换节日  [1-4]直达节日  [H]游园锦囊
```

### 1. 🔥 全域节庆热度与千分阶梯盛典
* **起步吉祥分**：系统基础热度从吉祥分 **666** 起步！
* **持续游园累加**：猜灯谜、摇灵签、放天灯、敲金鼓均可获得热度加分。
* **千分盛典阶梯引爆机制**：每跨越里程碑（1000、3000、5000……），系统将自动全屏触发一次【华彩盛典 · 万象共鸣】！烟花怒放、礼炮齐鸣、灵兽跃动、全景辉光爆发！

### 2. 🌟【万象盛典 · 华彩齐鸣】（按 `[ENTER]` 键）
一键引爆当前节日下的全部庆祝特效同框绽放：
* **中秋**：高空多角连珠大烟花、满月清辉暴涨、桂树震颤金雨狂卷、玉兔跃动捣药、万家灯火通明、天灯破晓长耀；
* **国庆**：二十八响三军礼炮齐鸣、万千庆典气球腾空蔽日、金色山河战鼓雷动、长城金辉闪耀；
* **新春**：百子连环大地红爆竹轰鸣、祥瑞金狮凌空起舞、财神天降元宝雨漫天洒落、春联生辉；
* **元宵**：江天烟雨画舫齐明、百盏水云灯蜿蜒汇入星河、双尾金鳞锦鲤腾跃江心。

### 3. 🎋【岁时灵签 · 卜问乾坤】（按 `[J]` 键）
真实竹筒摇签物理动画与解签音律，内置 8 款传统上吉运签（*月华如愿、蟾宫折桂、岁岁常安、紫气东来、山河壮丽等*），附带诗意判词与全景专属环境 Buff。

### 4. 🏮【民俗博古 · 猜灯谜与问答】（按 `[T]` 键）
涵盖中秋典故、国庆历史、新春礼俗与上元灯谜的精选博古题库，支持键盘 `[A]`、`[B]`、`[C]`、`[D]` 即时作答，连对获得热度奖励与专属金花喝彩。

## 🎮 三、双引擎运行方式

### 🌟 模式一：现代游戏 UI 交互端（强烈推荐 · 极具视觉美感）
- **在线即玩**：直接访问 [GitHub Pages 在线直达](https://sherlockyzz.github.io/mid-autumn-celebration/)。
- **本地秒开**：双击根目录下的 **`启动节日庆典.bat`**（或直接打开 `index.html`）。纯 HTML5 Canvas + 原生 Web Audio API，无需联网、零外部依赖、秒开即玩！

### 💻 模式二：C++17 纯原生终端字符端（黑客极客风）
- **直接运行**：双击运行根目录下的 **`festival_app.exe`**。
- **技术亮点**：
  - 基于 Windows 原生控制台 API 与 24-bit TrueColor ANSI；
  - 纵向半块像素（`▀` / `▄`）超分渲染，在纯字符黑框里跑出细腻像素动画；
  - 前后台双缓冲区差异比对输出，彻底解决字符终端闪烁顽疾。
