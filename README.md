# 🌕 宵月良宵 · 东方像素艺术中秋交互庆典系统

> **「月华如愿，游园踏月，人间烟火，万家常安」**  
> 本项目是一款基于 **现代 C++17** 打造的纯终端沉浸式中秋节庆彩蛋系统。深度融合东方古典美学、水墨留白韵味，并吸收了**《鸣潮》追月节**（“月华如愿”、“宵月会游园”、“心愿祈福”、“赏灯筑阁”、“卜问月”）与**《原神》逐月节**（“人间烟火气”、“万家灯火与清辉相映”、“珍肴致献美食”）的民俗游戏化精髓，将唯美像素艺术与高可玩性互动浓缩于一幅鲜活的东方中秋夜画卷之中。

---

## 📸 核心视觉与艺术设计

* **东方节庆色彩体系**：
  * **底色**：深邃幽寂的墨青与靛蓝夜空（`#060B19`），星汉隐现。
  * **第一视觉中心**：皓白温润的满月高悬中天（`#FFFDF8` ~ `#FFF8E7`），伴有薄云如纱、月华如练的漫射辉光。
  * **第二视觉中心**：神采奕奕的**东方像素玉兔**沐浴于月光露台之上，粉瓣长耳、赤朱明眸、温润白毫、手握金杵、青玉药臼，捣药时灵气升腾。
  * **点睛之笔**：金秋桂树暗香浮动、枝头挂垂朱红流苏灯笼、水岸飞檐翘角、澄江倒映金色波纹。
  * **大面积留白美学**：彻底摒弃廉价杂乱字符与调试界面，画面干净空灵、层次分明。

## 🎮 民俗互动与游戏化玩法详解

画面底部常驻**核心交互按键**与**无上限节庆热度**：
`🏮 热度: 666  [ENTER]盛典  [SPACE]烟花  [R]玉兔  [G]摇桂  [J]求签  [T]灯谜  [K]筑阁  [P]吟诗  [N]题名  [H]锦囊`

* **节庆热度机制**：
  * **起步底分**：系统基础热度值从吉祥分 **666** 起步！
  * **不设上限**：随着游园进程持续向上累积（如 780、888、1000、1200+...）。
  * **千分盛典阶梯引爆**：游园参与各项活动默默加分，**每增加 2000 点热度（1000、3000、5000……）系统均会自动触发一次【盛世良宵 · 华彩齐鸣】全景大盛典**！
  * **各活动热度增幅**：
    * 🌟 **最终全部活动（[ENTER]/[A]）**：一次性增加 **+334** 热度（直冲破千）！
    * 🎆 **放烟花**：每次 **+15**
    * 🐰 **玉兔捣仙芝**：每次 **+20**
    * 🍂 **摇落金桂**：每次 **+20**
    * 🏮 **挑灯弄影**：每次 **+15**
    * 📜 **月下题名**：每次 **+50**
    * 🎐 **祈愿天灯**：每次 **+35**
    * 🏮 **猜灯谜答对**：每次 **+50**
    * 🎋 **追月求灵签**：每次 **+30**
    * 🥮 **玉兔品名饼**：每次 **+30**
    * 🏯 **赏灯筑阁**：每次 **+30**
    * 📖 **赏月吟诗**：每次 **+20**

  * 🌕 **赏明月**：满月清辉暴涨，月华脉冲如水波向四周激荡；
  * 🍂 **摇落金桂**：月桂古树震颤，上百枚金瓣漫天旋转纷飞；
  * 🐰 **灵兔捣仙芝**：玉兔起跃捣药、欢快甩耳、仙玉臼内喷涌璀璨星芒；
  * 🏮 **万家灯火**：江畔长街瞬间进阶至四级「万家灯火」，楼阁金顶辉煌，万家红灯通明映照澄澈江波；
  * 🪔 **画舫燃灯**：朱红流苏灯笼全部炽热点亮；
  * 🎐 **祈愿天灯**：两盏祈愿孔明灯携千家心愿乘风漫游升空；

### 1. 🏮【宵月游园 · 雅趣猜灯谜】（按 `[T]` 键）
* **玩法精髓**：复刻传统中秋宵月游园灯下猜谜的民俗雅趣。
* **丰富题库**：内置 12 道精挑细选的中秋民俗、成语、文学、中药与地名灯谜。
* **互动机制**：
  * 支持键盘输入 `[A]`、`[B]`、`[C]`、`[D]`（或数字 `[1]~[4]`）即时提交选择。
  * 答对即刻获得 **+50 节庆热度**，累积连对记录，同时触发金色庆贺烟花与玉兔欢呼！
  * 支持按 `[ENTER]` 查阅谜底古籍考释，按 `[N]` 切换新谜题，按 `[ESC]` 退出。

### 2. 🎋【追月灵签 · 卜问月】（按 `[J]` 键）
* **玩法精髓**：借鉴传统摇签祈运，求得中秋吉签与全域祝福。

* **全景联动**：每一道灵签不仅带有诗意解语，更会**实时触发专属全域场景 Buff**（如月华清辉脉冲暴涨、金桂狂卷落英缤纷、万家灯火通明、天灯破晓等）！
* 按 `[SPACE]` 可再次摇取新签，按 `[ESC]` 领受赐福。

### 3. 🥮【中秋食韵 · 玉兔品名饼】（按 `[B]` 键）

## 🛠️ 技术架构亮点

1. **自研现代 C++17 纯终端引擎**：
   * **双缓冲机制（Double Buffering）**：彻底消除终端闪烁，仅输出差异字符。
   * **半块像素渲染（Half-block Subpixel）**：使用 `▀` 和 `▄` 结合前景/背景色，实现纵向分辨率翻倍（48 像素高度），让玉兔骨骼更柔和、月轮边缘更圆润。
   * **真彩色（24-bit TrueColor ANSI）**：平滑插值微光渐变与月晕光辉。
   * **纯正 UTF-8 宽度处理**：精准区分半角字符（宽1）与全角汉字/Emoji/特殊符号（宽2），彻底杜绝错位对齐问题。
2. **多线程/无阻塞硬件键盘监听**：
   * 采用 Windows Console ReadConsoleInputW 搭配 CRT `_kbhit()` / `_getwch()` 双重 Fallback，确保在中英文输入法状态下字符与功能键均 100% 毫秒级响应，永不漏键。
3. **物理与粒子系统**：
   * 包含速度、阻尼、浮力与扰动风力的真实粒子模拟（桂花、烟花火星、灵药星芒、孔明灯、月下流光墨迹）。
4. **高解耦插件体系**：
   * 附加功能（如 114 周年印章）采用 C++17 `__has_include` 自动发现机制，移除文件即可平滑脱耦，核心系统零污染。

## 🚀 编译与运行说明

### 推荐运行环境
* **操作系统**：Windows 10 / Windows 11
* **终端工具**：推荐使用 **Windows Terminal**（支持完整的 24-bit TrueColor、UTF-8 字符集与半块像素平滑绘制）
* **终端字体**：推荐使用支持等宽与中文的现代字体（如 *Cascadia Mono*、*Sarasa Gothic 等宽*、*JetBrains Mono*）
* **推荐窗口尺寸**：宽 80 列，高 24~28 行以上

### 快速启动
根目录下已预置编译完毕的单可执行程序，直接双击或在 PowerShell 中启动即可：
```powershell
.\festival_app.exe
```

### 源码重构编译（如需二次开发）
* **使用 g++ (MinGW-w64)**：
  ```powershell
  g++ -std=c++17 -O2 -I. -o festival_app.exe festival/main.cpp
  ```
* **使用 CMake**：
  ```powershell
  mkdir build; cd build
  cmake ..
  cmake --build . --config Release
  ```
* **运行自动化测试套件**：
  ```powershell
  .\tests\interactive_test.exe
  .\tests\snapshot_test.exe
  ```
