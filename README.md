# 🏮 中华华节盛典 · 岁时交互引擎系统
> **Chinese Traditional & National Festival Celebration Interactive Suite**  
> **双引擎架构：现代游戏级 Web GUI 端 ＋ 现代 C++17 纯原生终端字符端**

---

## 📖 项目概述

**「华夏岁时，山河共庆；月华如愿，万家常安」**

本项目是一款由深度东方美学驱动的**多节日全景交互庆典系统**。系统融合了东方古典传统色谱、水墨留白韵味与现代游戏化交互体验，吸收了传统节日礼俗与现代开放世界游戏（如《鸣潮》追月节、《原神》海灯节/逐月节）的沉浸式游园精髓。

针对不同使用场景与审美需求，系统提供**完全独立、功能互通的双引擎实现**：
1. **现代游戏 UI 交互端（Web / Desktop GUI）**：高规格游戏级交互界面、自研 Web Audio 零依赖多调性声音合成器、全屏物理水纹与粒子光影。
2. **现代 C++17 纯原生终端字符端（Console Engine）**：基于 Windows 原生控制台 API、24-bit TrueColor ANSI、纵向半块像素（`▀` / `▄`）超分渲染、双缓冲零闪烁输出。

## 🎮 运行方式与快速启动

### 🌟 模式一：现代游戏 UI 交互端（强烈推荐 · 极具美感）
- **一键极速体验**：双击运行根目录下的 **`启动节日庆典.bat`**（或直接双击 **`index.html`** 在任意现代浏览器中打开）。
- **完全免安装、零外部依赖**：纯 HTML5 Canvas + 原生 Web Audio API，无需联网、秒开即玩。
- **视觉与交互亮点**：
  - **动态粒子与物理模拟**：落樱金桂、飞舞红绸、烟火碎屑、漫天流星、波光水影。
  - **合成声学系统**：内置纯代码合成的古筝五声音阶、礼炮轰鸣、威武金鼓、噼啪爆竹声、轻灵铜铃。
  - **节日切换悬浮座舱**：顶部常驻节日切换 Dock 栏，支持鼠标点击或按键盘 `[1]`、`[2]`、`[3]`、`[4]` 及 `[TAB]` 循环切换。
  - **游戏化弹出视窗**：求签卜卦动画、灯谜答题闯关、自选春联题名、游园锦囊。

### 💻 模式二：C++17 纯原生终端字符端
- **快速运行**：直接双击运行根目录下的 **`festival_app.exe`**。
- **推荐运行环境**：
  - 操作系统：Windows 10 / Windows 11
  - 终端工具：推荐使用 **Windows Terminal**（完美支持 24-bit TrueColor、UTF-8 字符集与半块像素）
  - 终端字体：推荐 *Cascadia Mono*、*Sarasa Gothic 等宽*、*JetBrains Mono*
  - 窗口尺寸：建议宽 80 列以上，高 25~30 行以上
- **热键操作**：在终端内按下 `[TAB]` 或数字键 `[1]`、`[2]`、`[3]` 可瞬间无缝切换中秋、国庆、新春全景。

## 🕹️ 核心玩法与热度系统

画面底部常驻**核心交互提示**与**全域节庆热度**：
```text
🏮 热度: 666  [ENTER]华彩盛典  [SPACE]绚烂烟花  [TAB]切换节日  [1-4]直达节日  [H]游园锦囊
```

### 1. 🔥 全域节庆热度体系
* **起步吉祥分**：系统基础热度值从吉祥分 **666** 起步！
* **无上限持续累积**：游园参与各项民俗小游戏持续加分（+15 至 +50 不等）。
* **千分盛典阶梯引爆机制**：
  - 每增加 2000 点热度（**1000、3000、5000、7000……**），系统将自动全屏触发一次【华彩盛典 · 万象共鸣】！
  - 烟花怒放、礼炮齐鸣、灵兽腾跃、全景辉光爆发，呈现节庆高潮。

### 2. 🌟【万象盛典 · 华彩齐鸣】（按 `[ENTER]` 键）
* **玩法精髓**：一键引爆当前节日下的全部庆祝特效同框绽放！
* **中秋主题**：高空多角连珠大烟花、满月清辉暴涨、桂树震颤金雨狂卷、玉兔跃动捣药、万家灯火通明、天灯破晓长耀；
* **国庆主题**：二十八响三军礼炮齐鸣、万千庆典气球腾空蔽日、金色山河战鼓雷动、天安门与长城金辉闪耀；
* **新春主题**：百子连环大地红爆竹轰鸣、祥瑞金狮凌空起舞、财神天降元宝雨漫天洒落、春联生辉；
* **元宵主题**：江天烟雨画舫齐明、百盏水云灯蜿蜒汇入星河、双尾金鳞锦鲤腾跃江心。

### 3. 🎋【岁时灵签 · 卜问乾坤】（按 `[J]` 键）
* 真实竹筒摇签物理动画与解签音律，内置 8 款传统上吉运签（*月华如愿、蟾宫折桂、岁岁常安、紫气东来、山河壮丽等*）。
* 解签时不仅附带文雅诗意判词，更会实时激活全景专属环境 Buff！

### 4. 🏮【民俗博古 · 华夏问答与猜灯谜】（按 `[T]` 键）
* 涵盖中秋典故、国庆历史、新春礼俗与上元灯谜的精选博古题库。
* 支持键盘 `[A]`、`[B]`、`[C]`、`[D]` 即时作答，连对获得热度奖励与专属金花喝彩。

### 5. 📜【定制祈愿与自选春联】（按 `[W]` / `[C]` / `[N]` 键）
* 自由输入祝福寄语或在精选名联（如“九州日丽迎新岁，四海春温发泰亨”）中任意挑选，文字粒子升腾凝练至主匾额与楼门联幅之上。

## 🛠️ 技术架构亮点

```text
                        ┌──────────────────────────────────────────────┐
                        │      中华华节盛典 · 岁时交互引擎系统          │
                        └───────┬──────────────────────────────┬───────┘
                                │                              │
                ┌───────────────┴───────────────┐              │
                ▼                               ▼              ▼
     【C++17 纯原生终端引擎】        【现代 Web/Desktop GUI 引擎】     【自研声学合成器】
     ├─ 24-bit TrueColor ANSI        ├─ HTML5 高性能 Canvas 管线     ├─ Web Audio API
     ├─ 半块像素（▀/▄）纵向超分      ├─ 物理粒子、流体与扰动系统     ├─ 五声音阶古筝律动
     ├─ 双缓冲差异比对输出机制       ├─ 响应式毛玻璃拟真游戏UI       ├─ 真实火炮重低音
     ├─ Windows 原生事件轮询         ├─ 全域热度与阶梯里程碑调度     ├─ 爆竹声频调制
     └─ 多场景状态机（中秋/国庆/新春）└─ 4大节日全景无缝热切换        └─ 零外链音频文件
```

1. **终端核心引擎纯自研**：
   - **双缓冲机制（Double Buffering）**：通过前后台缓冲区差异比对，仅输出变动单元格，彻底解决控制台闪烁顽疾。
   - **半块像素超分渲染（Half-block Subpixel）**：利用 `▀` 与 `▄` 结合前景色与背景色，在字符终端内实现纵向像素翻倍渲染，构建细腻的像素画质。
   - **UTF-8 与 East Asian Width**：精准计算中英文字符显示宽度，杜绝多字节字符排版撕裂错位。
2. **零依赖声学合成**：
   - 彻底摆脱音频文件外链加载慢、跨域报错或体积庞大的缺陷，所有乐音、鼓点、爆鸣均通过 Web Audio 振荡器、增益节点与滤波器动态纯代码合成。
3. **高内聚低耦合组件化**：
   - 场景解耦规范，可随时扩充新节日；各组件（烟花、气球、狮子、玉兔、灯笼）支持独立生命周期管理。

## 🚀 编译与开发者指南

### 本地编译 C++ 终端引擎
* **使用 MinGW-w64 (g++)**：
  ```powershell
  g++ -std=c++17 -O2 -I. -o festival_app.exe festival/main.cpp
  ```
* **使用 CMake**：
  ```powershell
  mkdir build; cd build
  cmake ..
  cmake --build . --config Release
  ```
* **运行集成测试套件**：
  ```powershell
  g++ -std=c++17 -O2 -I. -o interactive_test.exe tests/interactive_features_test.cpp
  .\interactive_test.exe
  ```
