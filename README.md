### 2. 📐 智算拓扑工坊 (John Tromp Lambda Diagram Workstation)
- **极简电路式几何拓扑**：基于 John Tromp 的 Lambda Diagram 论文，抽象项映射为横梁，变量映射为垂直导线，无交叉无歧义呈现纯 $\lambda$ 演算。
- **五阶段 $\beta$-规约演进器**：`锁定红基` ➔ `关联形参` ➔ `溶解横梁` ➔ `代换接入` ➔ `最终整流`，全动画可逆推演。
- **23 项经典组合子与云端公式库**：内置 S-K-I 完备基、Church 算术（加/乘/幂）、Y 递归不动点、布尔逻辑门等，支持云端保存与导入导出。

### 3. ✨ 星汉算筹 · 天象演算法 (Celestial Constellation Hybrid Mode)
- **天象排盘**：将抽象横梁映射为夜空金色星宿横梁（玉宇飞檐），变量导线映射为青蓝周天星斗连线。
- **数理律动共鸣**：每单步执行一次 $\beta$-规约，系统通过 Web Audio API 合成五声音阶（宫商角徵羽）金石编钟谐波，并在苍穹对应红基坐标引爆粒子烟花。
- **AI 诗性注疏**：【智算司律灵仙】实时解析规约算理，自动撰写对仗工整的数理哲思楹联。

## 🚀 四、快速启动指南

### 方式 1：在线免安装直连体验（推荐）
直接访问 GitHub Pages：[**https://sherlockyzz.github.io/mid-autumn-celebration/**](https://sherlockyzz.github.io/mid-autumn-celebration/)

### 方式 2：全栈服务与本地体验
1. **一键启动全栈服务**：双击根目录下的 [`启动全栈服务.bat`](./启动全栈服务.bat)（或运行 `npm start`），自动启动端口 `3000` 服务并打开浏览器。
2. **一键启动纯前端庆典**：双击 [`启动节日庆典.bat`](./启动节日庆典.bat) 或直接打开 [`index.html`](./index.html)。
3. **运行 C++17 原生终端版**：双击运行 [`festival_app.exe`](./festival_app.exe)（推荐使用 Windows Terminal）。
4. **运行自动化测试套件**：
   ```bash
   npm test
   ```
