## 一、项目背景与时代机遇

### 1.1 计算机科学底层形式化理论的教学与普及痛点
作为理论计算机科学与函数式编程的通用母体，$\lambda$-演算（Lambda Calculus）是现代程序设计语言与形式化验证的核心基石。然而，传统教学通常依赖晦涩的符号串替换（如变量捕获、重命名 $\alpha$-转换），学生难以直观建立抽象空间认知。荷兰数学家 John Tromp 提出的 **Lambda 图（Tromp Diagrams）**以极简的二维电路拓扑表达变量绑定与函数作用，具有极高的几何美学与工程教学价值，但全球范围内一直缺乏高完成度的动态全栈实验仿真工作台。

### 1.2 中华岁时节令文明与数字文化传承新命题
中华民族的岁时节令（中秋、国庆、除夕、上元）承载着深厚的民族向心力与文化认同。在国家文化数字化战略推进下，新一代青年对“新国风”互动体验有着强烈渴望。然而，市面上绝大多数节庆产品属于“一次性孤岛”，节日一过即被废弃，且视觉塑料感严重、缺乏深度交互与个性化定制能力。

### 1.3 生成式 AI Agent 时代的跨学科融合契机
生成式人工智能（LLM & Agent）的发展，赋予了计算机“理解自然语言情感”与“执行符号形式推理”的双重潜能。打造一个贯通数理逻辑与人文意象的跨模态智能体，将抽象符号计算编译为可感知的多模态艺术，具有广阔的科研教学、文化传播与产业应用前景。

### 4.1 符号演算与传统美学的底层同构设计
1. **拓扑同构**：John Tromp 图由抽象横梁（Abstraction Beam）与变量垂直引线（Variable Wire）交错构成；中国传统飞檐门楼由横向额枋梁架与垂直立柱/春联对仗交错构成。
2. **格律同构**：在柯里-霍华德同构（Curry-Howard Isomorphism）中，证明即程序；而在诗词楹联中，上联与下联在词性、平仄上构成严密的**对偶范式（Dual Normal Form）**。
3. **参数化驱动**：Church 计数 $n = \lambda f. \lambda x. f^n x$ 在规约至最终整流范式后，其阶数直接作为输入管道，决定生成式连珠烟花的发射数量、古筝五声音阶的和弦排列与万家灯火的建筑层级！

   - Web Audio API 纯代码合成五声音阶古筝、编钟、礼炮重低音与大地红爆竹。
4. **AI 智能决策中枢**：

## 六、作品功能逐一深度剖析

### 6.1 模块一：【数律篇 · 形式化逻辑与 John Tromp 几何拓扑演算台】
* **五阶段 $\beta$-规约动态流线演进**：
  1. *锁定红基*：高亮待求值表达式核心，非红基背景柔和淡化；
  2. *关联形参*：虚线框选实参子图，高亮形参接收端点并绘制代换流向线；
  3. *溶解横梁*：$\lambda$ 抽象横梁与应用连接桥动态虚化溶解，开启双同心环插槽；
  4. *代换接入*：实参迷你接驳块直插形参插槽；若引用为 0 则呈现丢弃删除线；
  5. *最终整流*：规约式归位于几何稳态网格，完成单步化简。
* **单排 7 列纯 SVG 矢量控制栏**：包含重置、宏步后退、微步后退、自动播放、微步前进、单步规约、规约至范式，零冗余遮挡。
* **双语法解析与 23 款经典预设库**：支持经典记法（`\x. x`）与 De Bruijn 索引记法（`λλ1`），预设涵盖 Church 计数、S/K/I 组合子、Y 不动点组合子、阶乘运算等。
